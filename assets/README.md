# Background music for Reels

Place ONE royalty-free audio file here, named exactly:

    music.mp3

The reel generator loops/trims it to the video length and fades it out at the
end. The same track is used for every Reel (consistent audio branding).

## Where to get free, license-safe music

Use tracks explicitly cleared for use without attribution issues. Good sources:

- **YouTube Audio Library** (studio.youtube.com -> Audio Library) -- filter to
  "No attribution required." Download as MP3.
- **Pixabay Music** (pixabay.com/music) -- free for commercial use, no
  attribution required.
- **Free Music Archive** (freemusicarchive.org) -- check each track's license
  (look for CC0 or CC-BY).
- **Incompetech** (incompetech.com) -- Kevin MacLeod's library, free with the
  attribution he specifies.

## What to pick
- Calm, neutral, "lo-fi" or ambient instrumental works best for tip content --
  it shouldn't distract from reading the code.
- Instrumental only (no lyrics competing with on-screen text).
- 30-60 seconds is plenty; it loops automatically.

## Important reality check
Fully-automated Reels can ONLY use music you supply as a file like this.
Instagram's *trending* sounds (which get far more reach) can only be added
manually in the Instagram app -- the API cannot attach them. If a Reel starts
performing well, consider re-uploading it manually in-app with a trending sound
to maximize reach.

## If you skip this
If no music.mp3 is present, Reels still generate and post -- just silently
(no audio). Silent Reels underperform, so adding a track is recommended.
